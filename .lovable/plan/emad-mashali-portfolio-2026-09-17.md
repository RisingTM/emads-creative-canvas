# Emad Mashali Portfolio

## Build
- Create a polished single-page portfolio inspired by the uploaded editorial reference: ivory paper texture, black feature bands, thin serif typography, layered image frames, and restrained motion.
- Organize the supplied biography, projects, experience, skills, certifications, learning goals, and contact details into clear, responsive sections.
- Add replaceable visual placeholders for the portrait and each project, with accessible labels and stable mobile/desktop layouts.

## Private settings
- Add a discreet Settings entry protected by the supplied password.
- Verify the password only on the server and keep access in an encrypted, secure session cookie.
- Let the owner edit portfolio text, contact links, project links, and upload/replace images; include save feedback and a lock action.

## Lovable Cloud
- Store portfolio content in a single managed record so public visitors always see the latest saved version.
- Store uploaded portfolio images in managed storage and return optimized public URLs.
- Keep all editing and upload operations behind the password check; public visitors receive read-only content.

## Quality and verification
- Add project-link buttons, email and LinkedIn actions, mobile navigation, image loading states, reduced-motion support, and route-specific social metadata.
- Verify the public portfolio and password/settings workflow at desktop and mobile sizes.
